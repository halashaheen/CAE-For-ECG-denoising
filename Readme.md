# 1D Convolutional Autoencoder for ECG Signal Denoising

This repository contains a PyTorch implementation of a 1D Convolutional Autoencoder (CAE) designed to effectively remove common clinical artifacts from Electrocardiogram (ECG) signals. The model is engineered to isolate and filter out high-impact noise sources, such as Baseline Wander (BW) and Muscle Artifacts (MA), restoring degraded signals to a clean state while preserving essential morphology components required for subsequent diagnosis.

## Project Overview

ECG signals are inherently susceptible to corruption from several types of noise during acquisition. Two of the most problematic artifacts are:

1. **Baseline Wander (BW):** Low-frequency noise caused by patient respiration or movement.
2. **Muscle Artifacts (MA):** High-frequency noise generated by transient electromyographic activity.

Traditional digital filters often remove critical high-frequency clinical components (like the QRS complex) or fail to adapt to dynamic baseline shifts. This project demonstrates a deep learning approach using **1D Convolutional Autoencoders** to learn data-driven representations of clean ECG waveforms, isolating standard physiological characteristics from overlaying noise profiles.

## Dataset Architecture

The project leverages standard benchmark databases hosted on PhysioNet:

* **MIT-BIH Arrhythmia Database (`mitdb`):** Serves as the source for clean raw ECG signals (primarily lead MLII).
* **MIT-BIH Noise Stress Test Database (`nstdb`):** Serves as the source for real-world clinical noise records (`bw` and `ma`).

### Preprocessing and Splitting

1. **Normalization:** Individual records undergo standardization and are scaled tightly within a `[-1, 1]` amplitude range to ensure compatibility with the encoder-decoder non-linear activation functions.
2. **Segmentation:** Continuous signals are partitioned using a sliding window size of `2048` samples and a step size of `1024` samples (yielding a 50% window overlap).
3. **Data Splitting:** Patient records are rigorously segregated to prevent data leakage across train, validation, and test subsets:
* **Train Records (35 Patients / ~78%):** Records 100, 101, 106, 107, 108, 109, 111, 112, 113, 115, 117, 118, 122, 123, 124, 200, 201, 203, 205, 207, 208, 209, 210, 212, 213, 214, 215, 220, 222, 223, 228, 231, 232, 233, 234.
* **Validation Records (5 Patients / ~11%):** Records 119, 105, 103, 221, 217.
* **Test Records (5 Patients / ~11%):** Records 219, 202, 116, 121, 230.



### Synthetic Noise Synthesis

To simulate noisy real-world environments, baseline wander and muscle artifacts are mixed dynamically into clean segments at specific target Signal-to-Noise Ratio (SNR) levels: **0 dB, 1.25 dB, and 5 dB**.

## Model Architecture

The framework supports multiple 1D Convolutional models, including a standard `SimpleCAE` and a deep stacked variant `ResStackCAE` featuring residual skip connections to facilitate gradient flow across blocks.

### Key Design Choices

* **1D Convolutional Layers (`Conv1d`):** Exploit the temporal sequence properties of single-channel time-series data.
* **Batch Normalization (`BatchNorm1d`):** Stabilizes internal covariate shifts during training blocks.
* **Tanh Activation Function:** Utilized in the bottleneck or final reconstruction layers to explicitly map output waveforms to the preprocessed `[-1, 1]` normalization boundaries.

Below is an abstract design layout summarizing the internal dimensions of a stacked architecture mapping a 2048-sample input tensor down to a latent space bottleneck before projecting back to its full length:

```
Input Vector [1, 2048] 
       │
       ▼  (Encoder Blocks: Conv1d -> BatchNorm1d -> LeakyReLU -> MaxPool1d)
Feature Maps [32, 1024]
       │
       ▼
Feature Maps [64, 512]
       │
       ▼
Bottleneck Latent Space [64, 256] ── (Tanh / Core Latent Representation)
       │
       ▼  (Decoder Blocks: Conv1d -> BatchNorm1d -> LeakyReLU -> Upsample)
Reconstructed Vector [1, 2048] ── (Final Denoised Signal Output)

```

## Evaluation Metrics & Results

Performance evaluation hinges on tracking total **Signal-to-Noise Ratio Improvement ($\text{SNR}_{\text{imp}}$)**.

$$\text{SNR}_{\text{db}} = 10 \cdot \log_{10} \left( \frac{P_{\text{clean}}}{P_{\text{noise}}} \right)$$

$$\text{SNR}_{\text{improvement}} = \text{SNR}_{\text{denoised}} - \text{SNR}_{\text{noisy}}$$

### Empirical Test Performance

During comparative pipeline evaluations, deep models produced the following average filtering characteristics across testing blocks:

| Model Architecture Name | Mean Input Noisy SNR | Mean Output Denoised SNR | **Average SNR Improvement** | Final Evaluation Test Loss |
| --- | --- | --- | --- | --- |
| **`ResStackCAE`** | $2.07\text{ dB}$ | $8.99\text{ dB}$ | $\mathbf{6.92\text{ dB}}$ | $0.003432$ |
| **`DilatedResStackCAE`** | $2.07\text{ dB}$ | $8.78\text{ dB}$ | $\mathbf{6.72\text{ dB}}$ | $0.003473$ |
